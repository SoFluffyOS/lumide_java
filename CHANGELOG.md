# Changelog

## 1.0.0

- Initial release of Java support for Lumide IDE.
- Integrated Eclipse JDTLS for advanced Java language features.
- Support for multiple JDTLS versions based on installed JDK (Java 17-21+).
- Integrated downloader for automatic JDTLS installation.
- Commands for restarting, reinstalling, and upgrading the language server.
